    Connect your iPhone

    The coach learns what you open through Shortcuts → Automation. Make two automations for each app you want tracked.

    1. Open the Shortcuts app → Automation → + → App.
    2. Choose the app (e.g. Rednote), tick Is Opened only, and select Run Immediately. Tap Next → New Blank Automation.
    3. Add Get Contents of URL. Set the URL to: Tap Show More and set Method to POST.
    4. Add If → Contents of URL has any value, and put Show Notification with Contents of URL inside it.
    5. Repeat with Is Closed and this URL (no notification needed):

    Tap a URL to copy it. Change app=Rednote to the app's name for Douyin, Bilibili, YouTube and so on. The URL includes your access token, so keep it private.

    Tip: set up Focus or Screen Time limits too. The coach helps you reflect, but it can't lock apps.

    Your data

    Everything is stored on your own server. Only the usage summary and your messages are sent to Claude to write replies.
